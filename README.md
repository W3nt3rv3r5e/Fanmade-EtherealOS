## 📥 Installation Instructions

Downloading and running Fanmade-EtherealOS is designed to be simple:

1.  **Download:** At the top of this page, click the green **"<> Code"** button.
2.  **Export:** Click the **"Download ZIP"** option from the dropdown menu.
3.  **Extract:** Once the download is finished, extract the `.zip` file to your computer.
4.  **Done:** You now have the full source and assets ready for use.
